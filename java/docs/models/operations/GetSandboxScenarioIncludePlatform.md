# GetSandboxScenarioIncludePlatform

Fall back to the read-only platform tier when this journey holds no scenario of this name. Defaults to false, which reads this journey&apos;s org tier only.

## Example Usage

```java
import com.gbg.gocore.models.operations.GetSandboxScenarioIncludePlatform;

GetSandboxScenarioIncludePlatform value = GetSandboxScenarioIncludePlatform.TRUE;
```


## Values

| Name    | Value   |
| ------- | ------- |
| `TRUE`  | true    |
| `FALSE` | false   |
